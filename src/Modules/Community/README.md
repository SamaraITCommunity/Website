# Сообщества SITC

Страницы `/communities/` и `/progress/` — демонстрационные концепции для обсуждения. Вступление, темы, события, дерево развития и медали ещё не реализованы. Уровень и очки в личном кабинете принадлежат модулю Profile; профессиональные навыки не подтверждаются очками. Роли доступа принадлежат Identity.

Направления: сообщества по интересам, участие в нескольких группах, общие обсуждения, мероприятия и проекты; меры видимости, доступности и модерации следует согласовать до реализации.

Черновая иерархия: гильдия объединяет сообщества, пользователи вступают в сообщества, деятельность сообществ может формировать вклад гильдии. Правила начисления и подтверждения вклада ещё не определены. Страницы `/guilds/web/`, `/communities/php-samara/` и `/communities/samarajs/` — пример, не реальные членства.

Гильдии и сообщества могут быть связаны с задачами и уведомлениями участникам; концепция описана в [доске задач](../Tasks/README.md).

Страница `/participation/` описывает способы помочь, роли и текущее состояние достижений. Роли участия не назначают права сайта; сезонный рейтинг остаётся предложением.
