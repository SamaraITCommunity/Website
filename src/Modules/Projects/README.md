# Проекты SITC

Проект — направление или инициатива сообщества, которая может объединять события, материалы, команды и задачи. Предлагаются подкаст, конференции, митапы и хакатоны; состав и статус проектов нужно согласовать.

## Текущее состояние

Страница `/projects/` и отдельная страница `/projects/sitcast/` — статические черновики. На SITCast показаны найденные площадки и несколько выпусков по каталогу Soundstream; полнота аудио не проверена, фильтров пока нет. Полного проверенного архива SITCast, метрик, редактирования и управления командами проектов пока нет. Сведения о предложении и открытые вопросы: [разбор скетча](../../../docs/drafts/site-structure-review.md).

## Для дальнейшей разработки

Карточка проекта может содержать описание, формат, аудиторию, команду, результаты и способы подключения. Для SITCast сначала нужны источники выпусков, права на публикацию, проверка записей и решение о хранении. Сортировка архива — по дате от новых к старым, если она известна.
