# Каталог внешних ссылок SITC

Раздел `/links/` помогает найти сайты, каналы и чаты, связанные с самарским IT. Каталог различает официальные ресурсы SITC и независимые сообщества: ссылка не означает управление внешней площадкой. Один ресурс может относиться к нескольким темам или сообществам.

## Текущее состояние

Адреса хранятся в `content/links.md`; сведения о чатах предоставлены пользователем. Связи с тестовыми сообществами заданы вручную. Актуальность, наличие доступа и принадлежность площадок автоматически не проверяются.

## Вопросы для развития

- Поддержать название, тип площадки, адрес, направления и явные связи с сообществами.
- Уточнить владельцев и согласовывать публикацию и связи с представителями сообществ.
- Добавить проверку устаревших ссылок, предложения исправлений и модерацию.
