# Партнёры SITC

Партнёры могут поддерживать сообщество финансированием, площадками, экспертизой, информационной помощью и другими способами. Один партнёр может относиться к нескольким категориям. Публичная страница `/partners/` пока содержит описание категорий и пример карточки: каталог содержит статические примеры, а управление партнёрами, уровни и медали не подключены.

## Дальнейшая работа

1. Определить данные партнёра, согласие на публикацию и контакт организатора.
2. Создать отдельную модель партнёра и категории партнёрства; не смешивать организации и личные профили участников.
3. Определить прозрачные правила уровней и медалей, учитывающие разные виды вклада, а не только финансовую поддержку.
4. Добавить подтверждение вклада, историю изменений, исправление ошибок и права организаторов.
5. Подключить публичный каталог и карточки к данным, затем продумать контактную форму.
