# Материалы и наследие SITC

Контекст собирает доклады, презентации, видео, статьи и полезные материалы встреч, чтобы знания оставались доступными после событий. Материал может ссылаться на событие, авторов и сообщества; новые форматы должны добавляться без привязки к одной конференции.

## Текущее состояние

Раздел `/materials/` и страницы докладов — статические файлы `content/materials.md` и `content/talk-*`. Ссылки на некоторые записи неизвестны; названия докладов и авторы взяты из предоставленной программы. Загрузка файлов, поиск и редактирование через сайт не реализованы.

## Вопросы для развития

- Отдельно хранить источник, тип материала, авторство, событие и дату; поддержать материалы без события.
- Определить согласование авторов, разрешения на публикацию и исправление данных.
- Продумать внешние ссылки и хранение файлов, поиск, темы, доступность и архивирование.
- Связать материалы с профилями, гильдиями и сообществами; не начислять достижения автоматически до согласования правил.
